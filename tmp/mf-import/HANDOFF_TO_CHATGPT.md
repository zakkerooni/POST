# マネーフォワード（MF）仕訳インポートCSV 変換 引き継ぎ仕様書

このドキュメントは、`_Finance5th`（クレジットカード経費の仕訳管理シート）を
**マネーフォワード クラウド会計の「仕訳インポート」用CSV**に変換する作業の
確定ルールをまとめたもの。ChatGPT等に引き継いで同じ変換を再現するための仕様。

---

## 0. 全体像・目的

- **入力**: `_Finance5th` の仕訳データ（CSV。元はExcelの「仕訳」シートを書き出したもの）
  - 支払いはすべてクレジットカード（法人カード、名義: zakk）
  - 1行 = 1経費（借方のみ記載、貸方は空欄）
- **出力**: MFの仕訳インポート・テンプレート形式のCSV（26カラム）
- **変換の本質**: 借方（費用）＝元データの科目、貸方（相手勘定）＝クレカ未払いを役員借入金で処理する単式→複式変換
- 変換後、MFにインポート → 画面上で最終確認・微修正して確定する運用

---

## 1. CSV出力形式

| 項目 | 仕様 |
|---|---|
| 文字コード | **Shift-JIS (CP932)** ← MFの標準。必須 |
| 改行コード | CRLF |
| 区切り | カンマ、値のクオートは必要時のみ（`Anthropic, PBC` のようにカンマを含む場合は `"..."`） |
| カラム数 | **26列**（下記ヘッダー参照） |
| ヘッダー行 | あり（1行目） |
| No列 | 出力側で取引日昇順に1から振り直す（元データのNoは引き継がない） |

### 出力カラム（26列、順序厳守）
```
No, 取引日,
借方勘定科目, 借方補助科目, 借方部門, 借方取引先, 借方税区分, 借方インボイス, 借方金額(円), 借方税額,
貸方勘定科目, 貸方補助科目, 貸方部門, 貸方取引先, 貸方税区分, 貸方インボイス, 貸方金額(円), 貸方税額,
摘要, 仕訳メモ, タグ, MF仕訳タイプ, 決算整理仕訳, 作成日時, 作成者, 最終更新日時, 最終更新者
```

### 文字コードの注意
- ベトナム語等のダイアクリティック付き文字（Ô, ơ, ễ, ū 等）はCP932で表現できない
  → **ベース文字に置換**する（例: `HÔM`→`HOM`, `Phơ`→`Pho`, `Lễ Tân`→`Le Tan`, `sosū`→`sosu`）
- 日本語の濁点・半濁点は必ず保持すること（NFKD分解時に濁点を落とさない実装にする）

## 2. 抽出条件・除外条件

| 条件 | ルール |
|---|---|
| **仕訳ステータス** | 元データの「仕訳」列が **`yet`** の行だけを変換対象にする（`done` は変換済みなので除外） |
| 総合計行 | 「総合計」行・No空欄行はスキップ |
| 期間 | 2026年以降のみ（2025年以前の行があれば除外）。※過去バッチで実際に3件除外実績あり |
| 金額欠損 | 金額（税込）が空の行はスキップ |

> **重要**: 毎回「新しく `yet` になった分だけ」を渡される運用。既に `done`（インポート済み）は対象外。

---

## 3. 貸方（相手勘定）の決め方 ★固定

クレジットカード払い = 会社が立て替え = 役員（zakk）からの借入、という扱いで**全行一律固定**。

| 貸方項目 | 値 |
|---|---|
| 貸方勘定科目 | **`役員借入金`** ← 「金」まで付けるのが正式名称（`役員借入`ではない） |
| 貸方補助科目 | **`zakk`** |
| 貸方部門 | 空欄 |
| 貸方取引先 | 空欄 |
| 貸方税区分 | **`対象外`** |
| 貸方インボイス | 空欄 |
| 貸方金額(円) | 借方金額(税込)と**同額** |
| 貸方税額 | **0** |

---

## 4. 借方（費用）の作り方

### 4-1. 金額
- **借方金額(円)** = 元データ「金額（税込）」
- **借方税額** = 「金額（税込）」−「金額（税抜）」
  - 税抜が空欄の場合は税込と同額扱い（税額0）
- ※「請求金額（税込）」列は**使わない**

### 4-2. 税区分 ★固定
- 借方税区分 = **`課税仕入 10%`（全行一律）**
- 海外サービス（SUPPLUGINS, Anthropic, WIX 等）も **10%のまま**でよい（運用方針として確定）
- 税金の支払い（例: 源泉所得税及び復興特別所得税＝法人税の納付）も **課税仕入10%のまま**出力する
  （厳密には対象外だが、この運用ではMF側で処理せず10%固定で出す方針）

### 4-3. 部門・インボイス
- 借方部門 = **空欄**
- 借方インボイス = **空欄**

### 4-4. 借方取引先 ★重要
- **空欄にする**（元データの「支払先」は借方取引先に入れない）
- 支払先の情報は「摘要」に含まれているため不要、というのが確定運用

---

## 5. 勘定科目 対応表（借方勘定科目の正規化）★最重要

元データの借方勘定科目は表記ゆれ・略称があるため、下記に正規化する。
（過去のインポート後手修正から確定させたもの）

| 元データの勘定科目 | 変換後の勘定科目 | 補足 |
|---|---|---|
| 備品 | **備品・消耗品費** | |
| 消耗品 | **備品・消耗品費** | |
| 消耗品費 | **備品・消耗品費** | |
| 交通費 | **旅費交通費** | |
| 飲食費 | **会議費** | |
| 書籍代 | **新聞図書費** | |
| 駐車料金 | **車両費** | 補助科目に `駐車場費` を補完 |
| 印刷費（※勘定科目に入っている行） | **外注委託費** | 補助科目に `印刷外注費` を補完 |
| 不明 | **不明のまま** | 変換せず出力。インポート後にMF上で振り分ける（ユーザー判断） |
| 上記以外（会議費/通信費/新聞図書費/旅費交通費/外注委託費/保険料/源泉所得税及び復興特別所得税 等） | そのまま | 正しい科目はそのまま通す |

### 補助科目の正規化

| 元データの補助科目 | 変換後の補助科目 |
|---|---|
| 印刷費 | **印刷外注費** |
| 工事委託 | **デザイン外注費** |
| 上記以外（サービス利用料 / 宿泊費 / タクシー / miks駐車場費 / リサーチ費 等） | そのまま |

> 補助科目マッピングの注意:
> - 「印刷費」は**勘定科目に入っている場合**と**補助科目に入っている場合**の両方があり、どちらも変換対象。
>   - 勘定科目=印刷費 → 勘定科目を「外注委託費」、補助科目を「印刷外注費」に
>   - 補助科目=印刷費 → 補助科目を「印刷外注費」に
> - 「工事委託」（例: 宝来社 ジュプランサショーケース）→ 補助科目「デザイン外注費」

## 7. 変換ロジック（擬似コード）

```
for each 行 in 入力CSV:
    if No が空 or "総合計": skip
    if 仕訳ステータス != "yet": skip
    if 取引日.year < 2026: skip
    if 金額（税込） が空: skip

    税込 = 金額（税込）
    税抜 = 金額（税抜） or 税込
    借方税額 = 税込 - 税抜

    # 補助科目を先に正規化 → 勘定科目正規化（勘定科目側で補助を補完する場合があるため順序に注意）
    補助 = normalize_sub(元.借方補助科目)      # 印刷費→印刷外注費, 工事委託→デザイン外注費
    勘定, 補助 = normalize_account(元.借方勘定科目, 補助)
        # 備品/消耗品/消耗品費→備品・消耗品費
        # 交通費→旅費交通費, 飲食費→会議費, 書籍代→新聞図書費
        # 駐車料金→車両費(+補助:駐車場費), 印刷費→外注委託費(+補助:印刷外注費)
        # 不明→不明, それ以外→そのまま

    出力行 = [
        No(連番), 取引日,
        勘定, 補助, "", "",                       # 借方部門・取引先は空
        "課税仕入 10%", "", 税込, 借方税額,
        "役員借入金", "zakk", "", "", "対象外", "", 税込, 0,
        摘要.strip(), メモ, "", "", "", "", "", "", ""
    ]

出力を 取引日昇順 でソート → No を1から振り直し
Shift-JIS(CP932) + CRLF で書き出し（非対応文字はベース文字へ置換）
```

---

## 8. 検算・チェックポイント

- 借方金額(税込)の合計 = 元データ `yet` 行の税込合計 と一致するか確認
- 貸方金額合計 = 借方金額合計（複式なので必ず一致）
- マッピング表に無い勘定科目が出たら、そのまま出力しつつ**ユーザーに確認**する
  （過去に「書籍代」「源泉所得税及び復興特別所得税」が該当 → 都度判断）
- 税金・海外サービス・個人間送金など、税区分が気になる行は一応フラグして報告する

---

## 9. 運用フロー（毎回の流れ）

1. ユーザーが更新した `_Finance5th` のCSVを渡す
2. 「仕訳=yet の分だけ」を上記ルールで変換
3. マッピング表に無い科目・税区分が怪しい行があれば確認
4. Shift-JIS CSVを出力して渡す
5. ユーザーがMFにインポート → 画面で最終確認・微修正して確定
6. インポート後の手修正で新しい変換パターンが判明したら、対応表に追記して次回に反映

## 付録: 決まった経緯（背景メモ）

- **役員借入金 / zakk**: クレカ立替を役員（zakk）からの借入として処理する方針。ユーザー指定。
- **借方取引先を空欄に**: 初回は支払先を入れていたが、インポート後にユーザーが全削除 → 空欄が正解と確定。
- **税区分は一律10%**: 海外サービスや税金も含め、この運用では10%固定で出す（MF側で必要なら調整）。
- **不明はそのまま**: 「不明」勘定科目はインポート後にMF画面上で振り分けるので、変換段階では触らない。
- **勘定科目の正規化**: 元データの略称・表記ゆれ（備品→備品・消耗品費 等）はインポート後の手修正から逆算して確定させた。次回以降はこの対応表で手修正ゼロを目指す。
