# MF 仕訳インポート 変換ルール

`_Finance5th` の仕訳データを MoneyForward の仕訳インポートCSVに変換する際のルール。
※ 実際のインポート後修正（2026/06 バッチ）を反映した確定版。

## 出力フォーマット
- 文字コード: **Shift-JIS (CP932)**、改行: CRLF
- カラム: MFテンプレ26項目（`journal_sample.csv` 準拠）
- ベトナム語等のダイアクリティックは CP932 非対応 → ベース文字に置換（HÔM→HOM 等）

## 抽出条件
- `仕訳` ステータスが指定された値の行のみ（例: `yet` だけ）
- No・取引日が空、`総合計` 行はスキップ

## 固定値
| 項目 | 値 |
|---|---|
| 借方税区分 | `課税仕入 10%`（**全行一律**。海外サービスも10%のまま） |
| 貸方勘定科目 | `役員借入金`（※「金」付き） |
| 貸方補助科目 | `zakk` |
| 貸方税区分 | `対象外` |
| 貸方金額 | 借方金額（税込）と同額 |
| 貸方税額 | 0 |

## 金額
- 借方金額(円) = 金額（税込）
- 借方税額 = 金額（税込） − 金額（税抜）

## カラムマッピング
| MFテンプレ | ソース |
|---|---|
| 取引日 | 取引日 |
| 借方勘定科目 | 借方勘定科目（下記の正規化を適用） |
| 借方補助科目 | 借方補助科目（下記の正規化を適用） |
| 借方取引先 | **空欄**（支払先は入れない） |
| 摘要 | 摘要（前後の空白はトリム） |
| 仕訳メモ | メモ |

| 消耗品 | 備品・消耗品費 | |
| 消耗品費 | 備品・消耗品費 | |

## 空欄のまま出す項目
借方部門 / 借方インボイス / 借方取引先 / 貸方部門 / 貸方取引先 / 貸方インボイス /
タグ / MF仕訳タイプ / 決算整理仕訳 / 作成日時 / 作成者 / 最終更新日時 / 最終更新者

## 要レビュー（自動変換では確定できない）
- 借方勘定科目「不明」の行 → **そのまま「不明」で出力**（インポート後にMF上で振り分け）
- プロジェクト列は摘要・タグに転記しない（運用上不要）
- 税金の支払い（例: 源泉所得税及び復興特別所得税＝法人税）→ 勘定科目はそのまま、税区分も `課税仕入 10%` のまま出力（運用方針）
